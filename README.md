# StudyFlow – Responsive Landing Page

## About the Project

StudyFlow is a modern, responsive landing page designed for students. It focuses on productivity, study planning, goal tracking, and building better learning habits.

This project was developed as part of **UpStartInstern – Task 01**.

## Features

- Responsive navigation bar
- Modern hero section
- Study productivity feature cards
- About section
- Call-to-action section
- Responsive images
- Mobile-friendly layout

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

## Project Structure

```text
UpStartInstern-Task01/
│
├── index.html
├── style.css
└── README.md
```

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension.

## Responsive Testing

The website was checked at a mobile viewport width of 375px and on desktop.
